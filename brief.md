\# CampusEats — Project Brief



\## What

CampusEats is a food ordering system that lets students browse food items 

from campus canteens/cafes, add them to a cart, place orders, and track 

order status — similar to how a food delivery app works, but scoped to 

a campus.



\## Who

\- Customer (Student) — browses menu items, places orders, views order history

\- Admin — manages the menu/food items, views and updates order status



\## Nouns (resources/things in the system)

\- User (Customer)

\- Admin

\- Food Item / Menu Item

\- Cart

\- Order

\- Review



\## Verbs (actions/tasks on those nouns)

\- Browse food items (GET)

\- Add item to cart (POST)

\- Remove item from cart (DELETE)

\- Place an order (POST)

\- View order status (GET)

\- Update order status — admin only (PUT/PATCH)

\- Add a review for an item (POST)

\- Manage (add/edit/delete) menu items — admin only (POST/PUT/DELETE)
